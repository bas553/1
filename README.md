# Finance Desktop - Java + VS Code

## ต้องมี
- JDK 17 หรือใหม่กว่า
- VS Code
- Extension Pack for Java
- Maven

## เปิดโปรเจกต์
เปิดโฟลเดอร์ FinanceDesktop ใน VS Code

## รัน
เปิด Terminal แล้วใช้:

mvn clean javafx:run

หรือเปิด Main.java แล้วกด Run

## ข้อมูล
โปรแกรมจะสร้าง finance.db ในโฟลเดอร์โปรเจกต์อัตโนมัติ

## ฟังก์ชัน
- Dashboard รายรับ/รายจ่าย/คงเหลือ/หนี้
- เงินสด/ธนาคาร/บัตรเครดิต/สินเชื่อ
- บันทึกรายการ
- โน้ตลอยบน Desktop Always on Top
- คำนวณเงินกู้แบบลดต้นลดดอก
- ตารางผ่อนและดอกเบี้ยรวม
